# Qune forms

Quneic-published browser assets. Qune 0.3 permits only the interview form
`43f421c2-dc61-4ea3-b7b5-28d73773af12`.

Published address: https://form.qune.io/43f421c2-dc61-4ea3-b7b5-28d73773af12/

Answers remain in each participant's browser. Rust/Wasm performs the interview
computation locally; there is no server response collector. Browser draft storage
is not shared Qune Host admission. The three company policies are disclosure
previews. Hradtoraed presentation is provisional, with author approval pending.

`release.json` records the asset hashes. Deployment contains no participant drafts
or private source tree. Pages serves main/root; DNS is managed in Cloudflare.
